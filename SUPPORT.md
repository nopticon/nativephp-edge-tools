# Support

## Bugs

Please report bugs at:

https://github.com/nopticon/nativephp-edge-tools/issues

When reporting an issue, include:

- VS Code version
- NativePHP version
- Laravel version
- Operating system
- Example EDGE markup
- Expected behavior
- Actual behavior

## Feature requests

Feature requests are welcome through GitHub Issues:

https://github.com/nopticon/nativephp-edge-tools/issues
